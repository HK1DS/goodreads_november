승인된 Goodreads 실험 결정 기록

대상: HK1DS/goodreads_november, architect 브랜치의 TODO 5번과 8번.
최초 요청의 9번은 사용자가 8번으로 정정했다.

사용자 선택:
1. 8번은 MF 백본에서 먼저 검증한다.
   이유: 5번의 IKGR_dyn_nointent를 intent 없는 대조군으로 재사용하고 LightGCN보다 실행 부담을 줄인다.
   결론의 범위: MF 기반 모델. LightGCN 백본으로 일반화하지 않는다.
2. 모든 조건에 seed 2020, 2021, 2022를 사용한다.
3. 5번: BPR, IKGR_kgoff, IKGR_dyn_nointent 각 3 seed = 9회.
4. 8번: IKGR_dyn의 intent 제거율 0%, 5%, 10%, 20% 각 3 seed = 12회.
5. 합계 21회. 모든 비교는 동일 로컬 GPU에서 실행한다.
6. 설계 선택과 이유, 정확한 실행 조건, 코드, 테스트, 원시 지표, 분석 한계를 PR에 포함해 다른 사람이 검토할 수 있게 한다.

승인된 구현 기본값:
- train에 등장한 고유 아이템 연결 수로 intent를 정렬한다.
- 아이템 연결이 하나 이상인 intent가 비율의 분모다.
- 연결 수 내림차순, 동률 ID 오름차순; 제거 수는 floor(N * 비율).
- 해당 intent의 사용자/아이템 연결을 모두 제거한다.
- 원래 ID, 임베딩 행과 크기, 남은 연결 순서를 보존한다.
- 필터 적용 후 기존 kg_cap=32와 정규화를 적용한다.
- 제거율별 집합은 서로 포함 관계를 유지한다.
- 64차원, 최대 40 epoch, 2 epoch마다 검증, 3회 미개선 종료.
- validation NDCG@10 최고 체크포인트로 test 평가한다.
- 학습률 0.001, reg_weight 0.000001. 기존 deterministic 설정 유지.
- 인기도 페널티 0.25, 0.5, 1.0도 추가 학습 없이 평가한다.
- 대표 제거율은 3-seed 평균 validation NDCG@10으로 선택; 동률은 낮은 제거율. Test로 선택하지 않는다.
- 전체 제거율의 결과, seed 평균/표준편차, 사용자 단위 paired bootstrap CI와 Wilcoxon 결과를 공개한다.
- 기존 결과 및 512차원 결과와 섞지 않는다.

현재 실행 승인 범위:
- 이 작업 전용 Python/가상환경 설치, 데이터 복원, 테스트, 임시 시간 실측만 진행.
- 2026-11-10 추가 지시에 따라 intent 필터, 전용 실행 설정, GPU 사전 점검과 재실행 검증을 준비했다. 정식 21회 학습과 fork/PR 생성은 아직 시작하지 않는다.
- 임시 실측은 전체 train 데이터의 4 epoch 및 표본 평가를 사용한다.
- 임시 지표는 정식 정확도 결과로 사용하지 않는다.
- 2026-11-10 사용자 승인: 정식 평가 배치는 128명으로 고정한다. 전체 validation/test 사용자와 전체 아이템을 평가한다. 학습 배치 2048은 유지한다. 추가 배치/CPU 스레드 비교는 임시 실측이며 정식 결과가 아니다.
