# User segments (TO, test) — who gains from IKGR_lgcn_dyn_nointent vs LightGCN

Generated by `analyze_user_segments.py`. A = `IKGR_lgcn_dyn_nointent` (seeds 2020, 2021), B = `LightGCN` (seeds 2020, 2021); per-user metrics averaged over seeds, 62,142 test users (37,746 with a long-tail test item). CI = 95% bootstrap over users (1000 resamples). Per-seed column: A − B within each shared seed (2020, 2021).

Features use the TRAIN split only: `activity` = train interactions; `n_intents` = LLM intent count; `intent_disp` = intent dispersion, 1 - mean pairwise cosine; `shelf_entropy` = shelf (category) entropy, bits. Shelves on more than 50% of books are ignored for the entropy: `children-s-books`, `childrens`, `children`, `children-s`, `fiction`. If A does not use the LLM intents (`IKGR_lgcn_dyn_nointent`), the intent features only describe the user (what the LLM read in their train profile); they are not an input of A.
